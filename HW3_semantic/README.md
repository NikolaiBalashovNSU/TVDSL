HW3: Семантический анализатор и проверка типов для языка Funny
Реализация семантического анализатора в два прохода с иерархической таблицей символов (SymbolTable), строгой проверкой типов, вычислением контрактов (requires, ensures), поддержкой кванторов, выводом типов локальных переменных и аннотированием абстрактного синтаксического дерева (AST).

---

СТРУКТУРА
`semantic.py` — основной модуль семантического анализатора (класс SemanticAnalyzer, таблица символов, проверка совместимости типов, накопление позиционных ошибок).
`parser.py` — синтаксический анализатор и классы узлов AST с точным отслеживанием позиций (line, col).
`test_semantic.py` — комплексный набор позитивных и негативных тестов для проверки семантики.
`grammar_spec.txt` — спецификация поддерживаемых конструкций, типов и операций языка Funny.
`dfa_table.json` — таблица переходов лексера.
`README.md` — документация проекта.

---

ЗАПУСК

Убедитесь, что файлы парсера (parser.py) и таблицы лексера (dfa_table.json) находятся в рабочей директории.

Запуск тестов семантического анализа
python3 test_semantic.py
