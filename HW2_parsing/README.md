HW2: Синтаксический анализатор (Парсер) для языка Funny
Реализация синтаксического анализатора (парсера) методом **рекурсивного спуска (LL(1))** с интеграцией лексера, построением AST, поддержкой контрактов, кванторов, десахаризацией массивов и устойчивой обработкой ошибок в режиме паники.

---

Структура проекта
* `parser.py` — основной модуль парсера (классы AST, логика рекурсивного спуска, восстановление после ошибок, тесты).
* `lexer_generator.py` — генератор лексера и ДКА-таблицы.
* `dfa_table.json` — таблица переходов лексера.
* `grammar.txt` — финальная грамматика языка Funny.
* `README.md` — документация проекта.

---

ЗУПУСК
1. Генерация таблицы лексера
Убедитесь, что у вас установлен Python 3. Сгенерируйте табличный файл ДКА:
python3 lexer_generator.py
2. Запуск программы
python3 parser.py
